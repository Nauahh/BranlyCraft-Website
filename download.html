Installe le Launcher

Lance le fichier téléchargé pour installer BranlyCraft Launcher. Windows va afficher un avertissement — voici comment le contourner.

🚀
BranlyCraft-Launcher-setup-1.0.35.exe
Windows · 244 MB · NSIS Installer
Télécharger
Windows va afficher cet avertissement
Comment contourner cet avertissement
1
Clique sur "Informations complémentaires" (le lien bleu souligné en bas de la fenêtre bleue)
2
Un bouton "Exécuter quand même" apparaît — clique dessus
3
L'installation démarre. Suis les étapes et BranlyCraft Launcher s'installe sur ton PC
4
Lance le launcher, connecte-toi avec ton compte Microsoft et rejoins le serveur !
